🚀 PRÓXIMOS PASOS (TÚ)
─────────────────────────────────────────────────────────────────────────

1. EXPLORAR CÓDIGO
   $ cd tienda_virtual
   $ ls -la    # Ver estructura
   $ cat README.md    # Leer guía

2. INSTALAR DEPENDENCIAS
   $ cd backend
   $ npm install

3. CONFIGURAR ENTORNO
   $ cp .env.example .env
   $ nano .env    # Editar valores

4. INICIAR SERVIDOR
   $ npm run dev
   # ✅ Server running on localhost:5000

5. SERVIR FRONTEND
   $ cd frontend
   $ python -m http.server 8000

6. ABRIR EN NAVEGADOR
   $ open http://localhost:8000

7. EXPLORAR
   - Navega el sitio
   - Prueba carrito
