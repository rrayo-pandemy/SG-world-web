🆘 SOLUCIÓN DE PROBLEMAS:
───────────────────────────────────────────────────────────────────────────────

"Página en blanco en http://localhost:8000"
└─ Abre DevTools (F12) y revisa la consola JavaScript
└─ Asegúrate que los archivos CSS y JS cargan correctamente
└─ Recarga:  Ctrl+Shift+R   (cache clear)

"Carrito no persiste después de recargar"
└─ Verifica que localStorage no está deshabilitado
└─ En DevTools: F12 → Application → Local Storage
└─ Debería estar vacío inicialmente (se llena al añadir items)

"Animaciones no se ven"
└─ Esto es normal en navegadores antiguos
└─ En Chrome/Firefox/Edge funciona perfectamente
└─ Disable Motion está habilitado en accesibilidad

"Backend no inicia (NPM no encontrado)"
└─ Necesitas instalar Node.js desde nodejs.org
└─ Versión requerida: 18.0.0 o superior
└─ Reinicia el terminal después de instalar
└─ Luego: npm install && npm run dev
